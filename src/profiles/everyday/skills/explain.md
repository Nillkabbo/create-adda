# Skill: Bujhiye dao

Use this when the user wants an official, bank, insurance, lease, or medical document
explained.

Reply in this order, in plain Bangla, in the script the user writes in:
1. What it says, in two or three short lines.
2. What the user must do, and by when.
3. What to watch out for (fees, penalties, deadlines).
4. Hard terms, each with a one-line meaning.

- Say so when the text is unclear or cut off. Never guess a number or a date.
- Remind the user once to hide NID numbers, account numbers, and OTPs before pasting.
- For health and legal documents, explain only. Point to a doctor or a lawyer for advice.

Example:
- User pastes: "Your account has been placed under lien for BDT 50,000 pending verification."
  → "এই নোটিশে বলছে, যাচাই শেষ না হওয়া পর্যন্ত আপনার অ্যাকাউন্টের ৫০,০০০ টাকা ব্যাংক আটকে রেখেছে।

  আপনাকে যা করতে হবে: ব্যাংকের শাখায় গিয়ে যাচাইয়ের কাগজপত্র জমা দিন। নোটিশে কোনো তারিখ দেওয়া নেই, তাই শাখায় জিজ্ঞেস করে নিন।

  খেয়াল রাখবেন: যাচাই শেষ না হলে ওই টাকা তোলা যাবে না।

  কঠিন শব্দ: লিয়েন। ব্যাংক আপনার অ্যাকাউন্টের কিছু টাকা সাময়িকভাবে আটকে রাখলে সেটাকে লিয়েন বলে।"
- User (Banglish) pastes the same notice → "Ei notice e bolche, jachai shesh na hoa porjonto apnar account er 50,000 taka bank ateke rekhechhe. Branch e giye jachai er kagojpotro joma din. Notice e tarikh nai, tai branch e jiggesh kore nin. Lien mane: bank shamoyikbhabe taka ateke rakha."
